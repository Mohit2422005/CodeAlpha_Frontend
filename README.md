# 🖼️ Modern Responsive Image Gallery

A modern, responsive image gallery built using **HTML, CSS, and Vanilla JavaScript**. The project provides an interactive browsing experience with category filtering, hover effects, a fullscreen lightbox, and keyboard navigation.

🔗 **Live Demo:** `https://Mohit2422005.github.io/CodeAlpha_Frontend/`

---

## 📌 About the Project

This project was developed as a frontend development project to demonstrate practical skills in:

* Responsive web design
* CSS Grid layout
* JavaScript DOM manipulation
* Event handling
* Interactive UI components
* Image filtering
* Lightbox implementation
* Smooth CSS animations and transitions

The gallery adapts to different screen sizes, providing a consistent experience across desktop, tablet, and mobile devices.

---

## ✨ Features

### 📸 Responsive Gallery

* CSS Grid-based image layout
* Automatically adapts to different screen sizes
* Optimized layout for desktop, tablet, and mobile

### 🔍 Lightbox Viewer

* Click any image to open it in fullscreen view
* Previous and Next navigation
* Close button
* Image counter

### 🏷️ Category Filtering

Filter images by:

* All
* Nature
* Travel
* Architecture
* Animals

### 🎨 Hover Effects

* Image zoom animation
* Smooth overlay animation
* Image title and category information

### ⌨️ Keyboard Navigation

The lightbox supports keyboard controls:

| Key   | Action         |
| ----- | -------------- |
| `←`   | Previous image |
| `→`   | Next image     |
| `Esc` | Close lightbox |

### 📱 Responsive Design

The layout automatically changes according to screen size:

* 🖥️ Desktop → 4-column gallery
* 💻 Tablet → 2-column gallery
* 📱 Mobile → 1-column gallery

## 🚀 Deployment

This project can be deployed easily using **GitHub Pages**.

### GitHub Pages Setup

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/ (root)`
5. Click **Save**.

After deployment, your website will be available at:

``
https://Mohit2422005.github.io/CodeAlpha_Frontend/
```
